# Tell Me a Joke

A fun and simple web application that shows random jokes in **English** or **Bangla**. You can click the button to get a new joke every time! Built with **HTML**, **Tailwind CSS**, and **JavaScript**.

## Live Demo

Check out the live demo here: [Tell Me a Joke](https://comfy-kangaroo-fe6680.netlify.app/)

## Features

- Choose between **English** or **Bangla** jokes when the page loads.
- Get a **random joke** on page load.
- Click the **"Show Another Joke"** button to see a new joke.
- Fully responsive design using **Tailwind CSS**.
- Fun and interactive UI with animations.
